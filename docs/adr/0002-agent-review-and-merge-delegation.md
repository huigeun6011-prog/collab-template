# ADR-0002: 에이전트 리뷰와 Merge 위임 범위

- 상태: 승인됨 (프로젝트 책임자 지시)
- 날짜: 2026-11-17
- 작성: AI-BOOTSTRAP-01

## 배경

초기 설계는 공식 브랜치로의 최종 Merge를 사람이 하도록 했다. 프로젝트 책임자는 이 방식이
"에이전트들이 협업하게 한다"는 목적에 어긋난다고 지시했다. 사람이 반복 작업의 병목이 되어서는 안 된다.

## 결정

1. 에이전트는 다른 에이전트가 작성한 PR을 독립 리뷰하고, 통과하면 Merge할 수 있다.
2. 작성자는 자기 PR을 리뷰하거나 Merge 판단의 근거로 삼지 않는다. 리뷰어는 다른 식별자여야 한다.
3. Merge 전 필수 조건: 리뷰 `통과`, PR 본문의 검증 결과, 모든 완료 조건 충족.
4. 다음은 계속 **사람의 사전 승인**이 필요하다.
   - 저장소 공개 범위 변경, 삭제
   - 강제 push, 이력 변경
   - 중요 데이터 삭제
   - 인증 및 권한 확대
   - 유료 서비스 도입
   - 브랜치 보호 정책 변경
   - 버전 태그와 릴리스
5. 에이전트 리뷰는 GitHub의 공식 Approve가 아니다. 같은 계정을 공유하므로 정식 승인 기록을 만들 수 없고, 만들지 않는다.

## 결과

- 사람은 위험한 결정과 릴리스만 판단하고, 일상 PR 흐름에서는 빠진다.
- 리뷰의 독립성은 식별자 규칙과 별도 실행 세션에 의존한다. 기술적으로 강제되지 않는다는 한계가 있다.
- 신뢰 경계가 더 필요해지면 GitHub Apps 기반 인증 분리를 검토한다.
