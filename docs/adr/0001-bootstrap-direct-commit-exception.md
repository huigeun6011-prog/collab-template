# ADR-0001: 초기 부트스트랩 커밋의 main 직접 작업 예외

- 상태: 승인됨
- 날짜: 2026-11-17
- 작성: AI-BOOTSTRAP-01 (사용자 지시에 따라 수행)

## 배경

협업 규칙은 공식 브랜치(main)에 직접 작업하는 것을 금지한다. 그러나 저장소가 비어 있는 상태에서는
Pull Request의 기준(base) 브랜치가 존재하지 않으므로 첫 커밋은 PR로 만들 수 없다.

## 결정

저장소 생성 시 **최초 커밋 1개에 한해** main에 직접 push한다.
내용은 README, `.gitattributes`, `.collab/version`, 이 ADR로 제한한다.

## 결과

- 이후 모든 변경은 Issue → 브랜치 → PR로 진행한다.
- 브랜치 보호는 최초 커밋 이후 적용한다. 설정 변경은 사용자 승인 사항이다.
- 이 예외는 다시 사용하지 않는다.
